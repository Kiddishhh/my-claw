# 分析结果与报告

Daytona 模式通过 execute 运行独立 Python 计算与绘图代码，输出 CSV/XLSX、图表和报告。后文工具名/result_id 仅适用于本地表格工具模式；远程模式保留同等的数据来源、精度和交付约束，不依赖平台 tools 模块。

1. 确保有本次 analyze_table 返回的有效 result_id，记录来源、指标、分组和过滤口径。
2. 选择图表：类别对比用 bar，按 ISO 日期分组后的趋势用 line，两个数值维度用 scatter。
3. plot_analysis 指定真实结果列 x/y，默认 y=value。title、x_label、y_label 写清指标和单位。
4. 类别/时间轴标签必须唯一；多维分组导致同一标签重复时重新聚合，不把多行错误叠为一条趋势。图表只支持1～1000行，不自动抽样。
5. 图表值仅用于显示，精确结果以 result.json / 导出表格的十进制字符串为准。不要因渲染精度改变金额口径。
6. 先绘图，再 export_report：报告会引用该结果目录已生成的图表。导出包含完整结果 CSV/XLSX、Markdown 报告；报告只预览50行。
7. export_report 自动写入来源及文件哈希、分析参数和行数变化。模型最终回复概括核心结论、支持它的已计算数值、数据局限和产物路径。

## 调用示例

```json
{"result_id":"使用真实返回的ID","x":"product","y":"value","chart_type":"bar","title":"已付款产品销售额","x_label":"产品","y_label":"销售额（元）"}
```

```json
{"result_id":"使用同一个真实ID","title":"销售分析报告"}
```

## 交付边界

- 不修改输入文件，不使用用户标题作为输出路径。产物位于当前工作目录 `outputs/analysis/<result_id>/`。
- XLSX 数值按文本导出以保留 Decimal 精度；CSV 中疑似公式文本可能增加单引号，不等于原始字段内容已改变。
- 空结果要说明过滤后没有数据，不生成虚假的零值图。图表或导出失败时明确哪个阶段失败，不将文件名当作成功证据。
- 描述趋势与关联，不能据此宣称因果或统计显著性。缺少币种/统计口径时先确认。
- 仅返回必要摘要和输出路径；不要重新打印完整提示词、历史消息或全部数据。
